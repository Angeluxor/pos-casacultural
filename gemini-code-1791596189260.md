# Contexto del Proyecto: POS Casa Cultural

## 1. Entorno y Parámetros del Sistema
* **Zona Horaria y Localidad:** Toda marca de tiempo (timestamps) en la base de datos, cierres de caja y auditorías deben registrarse utilizando la zona horaria de Medellín, Antioquia, Colombia (America/Bogota, UTC-5).
* **Moneda:** Peso Colombiano (COP). Los cálculos financieros deben considerar la precisión adecuada para esta moneda (sin decimales para pagos en efectivo).
* **Stack Tecnológico:** Backend en FastAPI, ORM con SQLAlchemy, Base de datos PostgreSQL.

## 2. Reglas de Negocio (Core Transaccional)
* **Atomicidad Estricta:** Las operaciones de venta y recaudo operan bajo transacciones ACID. La creación de una factura, sus detalles, los abonos (pagos) y la afectación a la caja deben ejecutarse en un único `db.commit()`. Si algo falla, se exige un `db.rollback()`.
* **Caja Centralizada:** No se pueden registrar ventas, pagos ni gastos si la Caja no se encuentra en estado `ABIERTA`. Todo flujo de dinero (entradas, salidas, abonos, ingresos extraordinarios) debe quedar registrado en la tabla `caja`.
* **Pagos Múltiples:** Una factura soporta múltiples métodos de pago simultáneos (ej. Efectivo + Transferencia) o pagos parciales a lo largo del tiempo. 
* **Inventario (Kardex):** Toda alteración de stock (venta, compra, devolución) debe generar un registro inmutable de auditoría.

from sqlalchemy import Column, Integer, String, Float, ForeignKey, DateTime, Enum, Boolean
from sqlalchemy.orm import relationship
import datetime
import enum

class EstadoFactura(enum.Enum):
    PENDIENTE = "Pendiente"
    PAGADO_PARCIAL = "Pagado Parcial"
    PAGADA = "Pagada"
    ANULADA = "Anulada"

class FormaPago(enum.Enum):
    EFECTIVO = "Efectivo"
    TRANSFERENCIA = "Transferencia"
    TARJETA = "Tarjeta"
    OTRO = "Otro"

class TipoMovimientoCaja(enum.Enum):
    ENTRADA = "Entrada"
    SALIDA = "Salida"
    APERTURA = "Apertura"
    CIERRE = "Cierre"

class TurnoCaja(Base):
    __tablename__ = "turnos_caja"
    id = Column(Integer, primary_key=True, index=True)
    fecha_apertura = Column(DateTime, default=datetime.datetime.utcnow)
    fecha_cierre = Column(DateTime, nullable=True)
    saldo_inicial = Column(Float, default=0.0)
    saldo_final_real = Column(Float, nullable=True)
    abierta = Column(Boolean, default=True)

class Cliente(Base):
    __tablename__ = "clientes"
    id = Column(Integer, primary_key=True, index=True)
    nombre = Column(String, index=True)
    documento = Column(String, unique=True, index=True)
    facturas = relationship("Factura", back_populates="cliente")

class Producto(Base):
    __tablename__ = "productos"
    id = Column(Integer, primary_key=True, index=True)
    codigo = Column(String, unique=True, index=True)
    nombre = Column(String, index=True)
    precio = Column(Float)
    stock = Column(Integer, default=0)

class Factura(Base):
    __tablename__ = "facturas"
    id = Column(Integer, primary_key=True, index=True)
    cliente_id = Column(Integer, ForeignKey("clientes.id"), nullable=True)
    fecha = Column(DateTime, default=datetime.datetime.utcnow)
    total = Column(Float, default=0.0)
    saldo = Column(Float, default=0.0)
    estado = Column(Enum(EstadoFactura), default=EstadoFactura.PENDIENTE)
    
    cliente = relationship("Cliente", back_populates="facturas")
    detalles = relationship("DetalleFactura", back_populates="factura")
    pagos = relationship("Pago", back_populates="factura")

class DetalleFactura(Base):
    __tablename__ = "detalles_factura"
    id = Column(Integer, primary_key=True, index=True)
    factura_id = Column(Integer, ForeignKey("facturas.id"))
    producto_id = Column(Integer, ForeignKey("productos.id"))
    cantidad = Column(Integer, default=1)
    precio_unitario = Column(Float)
    subtotal = Column(Float)
    
    factura = relationship("Factura", back_populates="detalles")

class Pago(Base):
    __tablename__ = "pagos"
    id = Column(Integer, primary_key=True, index=True)
    factura_id = Column(Integer, ForeignKey("facturas.id"))
    fecha = Column(DateTime, default=datetime.datetime.utcnow)
    valor = Column(Float)
    forma_pago = Column(Enum(FormaPago))
    
    factura = relationship("Factura", back_populates="pagos")

class RegistroCaja(Base):
    __tablename__ = "caja"
    id = Column(Integer, primary_key=True, index=True)
    turno_caja_id = Column(Integer, ForeignKey("turnos_caja.id"))
    fecha = Column(DateTime, default=datetime.datetime.utcnow)
    tipo = Column(Enum(TipoMovimientoCaja)) 
    referencia = Column(String)
    forma_pago = Column(Enum(FormaPago))
    monto = Column(Float)
    observacion = Column(String, nullable=True)
